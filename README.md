# TodoList

A simple, efficient, and user-friendly application to help you manage your daily tasks, stay organized, and boost your productivity.

## Key Features

This application focuses on the core features required for effective task management:

* **Create Tasks:** Easily add new tasks to your list.
* **Mark as Complete:** Toggle the status of any task to "completed" or "pending."
* **Delete Tasks:** Permanently remove tasks from the list.
* **Task Persistence:** Tasks are saved (e.g., using Local Storage or a database) and remain available even after closing the application.

## Technology Stack

Based on typical modern web development for a project of this nature:

* **Frontend:** HTML5, CSS3, JavaScript (or a modern framework like React/Vue/Angular)
* **Build Tool:** Webpack / Vite (or similar)
